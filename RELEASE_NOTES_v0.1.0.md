# Codex Token Overlay v0.1.0

> **Unofficial / Not affiliated with OpenAI.**

This is the first public release of the Windows desktop overlay.

Highlights:

- Incremental JSONL parsing for live local Codex session usage.
- Portable PyInstaller single-file Windows x64 executable.
- Tray icon with Show/Hide, scope switching, opt-in Windows startup and Quit.
- Position memory under `%LOCALAPPDATA%\CodexTokenOverlay`.
- Automatic Chinese/English UI selection.
- Read-only local session access; no `auth.json`, API keys, `.env` files or network connections.

Asset: `CodexTokenOverlay-v0.1.0-windows-x64.exe`

The executable is unsigned. Verify it with `SHA256SUMS.txt`; Windows SmartScreen may show a first-run warning.
